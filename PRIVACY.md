# Privacy Policy

utah-jobs is a personal job tracker used only by its author, Santiago Bolano. It is not offered to anyone else.

**Google data.** The app asks for the `drive.file` permission, which lets it create Google Docs (tailored resumes) in a "Tailored Resumes" folder and manage only the files it created. It cannot see or change any other file in your Drive. It does not read, collect, sell or share any Google user data.

**Other data.** Job postings come from public job boards. Resume content is stored privately by the author and sent to the Anthropic API only to draft a tailored resume.

**Revoking access.** You can remove the app's access at any time at <https://myaccount.google.com/permissions>.
